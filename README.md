# Академия Руслана Шипицына

Публичный прототип многостраничного сайта образовательной Академии.

## GitHub Pages

https://ranhomer2010-sketch.github.io/ruslan/

## Резервное демо

https://anm-rehab.pastel-seal-2668.chatgpt.site

## Реализовано

- адаптивная главная страница
- каталог направлений
- отдельные страницы программ
- раздел расписания
- форма-прототип с выбором MAX или телефона
- проекты документов по персональным данным
- отсутствие реальной отправки заявок и аналитики до подключения российского сервера

## Планируемый следующий этап

- админка для программ и календаря
- отправка уведомлений менеджеру через официальный MAX Bot API
- сохранение версии и времени согласия пользователя
- защита формы от спама
- перенос изображений и данных на российскую инфраструктуру

## Локальный запуск

```bash
npm install
npm run dev
```

Проект находится на стадии прототипа. Даты, цены, реквизиты и юридические тексты требуют подтверждения Академией перед коммерческим запуском.
